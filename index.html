Arduino.

Arduino - Programación Modular.

  1. La programación modular consiste e dividir un programa grande en pequeñas partes llamadas módulos. Cada módulo se encarga de realizar una tarea específica.

    En Arduino, una de las principales herramientas para trabajar de forma modular son las funciones.

    En lugar de escribir todo el código dentro de setup() y loop(), podemos crear funciones para separar las distintas tareas del programa.

    Por ejemplo, un programa podría tener una función para:

    1. Encerder un LED.
    2. Apagar un LED.
    3. Leer un botón.
    4. Mostrar un mensaje.
    5. Calcular un valor.

    Esto permite que el código sea más ordenado, fácil de leer, reutilizable y sencillo de modificar.

    Ejemplo sin funciones 
        void setup(){
        pinMode(13, OUTPUT);
    }

    void loop(){
        digitalWrite(13, HIGH);
        delay( 1000);
        
        digitalWrite(13, LOW);
        delay(1000);
    }

    Todo el funcionamiento está escrito directamente dentro del loop().

    Ejemplo utilizando una función.
        void parpadear(){
        digitalWrite(13, HIGH);
        delay(1000);
    
        digitalWrite(13, LOW);
        delay(1000);
    }
    void setup(){
        pinMode(13, OUTPUT);
    }
    
    void loop(){
        parpadear();
    }

    Ahora la tarea de haccer parpadear el LED está separada en una función.

    La función puede ser llamada todas las veces que sea necesario: 

        loop(){
        parpadear();
        parpadear();
        parpadear();
        parpadear();
    }


  2. Estructura de una función.

    Una función puede tener diferentes elementos: 

        tipo nombre(parámetros) {
        // instrucciones
    }

    Por ejemplo: 

        void encender(){
        digitalWrite(13, HIGH);
    }

    En este caso:

    • void → Indica que la función no devuelve ningín valor.
    • encender → Es el nombre de la función.
    • () → Indica que la función no recibe parámetros.
    • { } → Contienen las instrucciones que ejecutará la función.

    Para ejecutar la función: 

        encender();


  3. Función sin parámetros y sin retorno

    Es el tipo de función más sencilla.

    La función no recibe información y no devuelve ningún resultado.

    Ejemplo: 
        void encenderLed(){
        digitalWrite(13, HIGH);
    }

    Para utilizarla: 

        encenderLed();

    Programa completo: 
        void encenderLed() {
        digitalWrite(13, HIGH);
    }

    void setup(){
            pinMode(13, OUTPUT);
    }

    void loop(){
        encenderLed();
        delay(1000);
    
        digitalWrite(13, LOW);
        delay(1000);
    }

    La función encenderLed() solamente realiza una acción.



  4. Función con parámetros y sin retorno.

    En este caso, la función recibe información mediante parámetros, pero no devuelve un resultado.

    Esto permite que una misma función pueda trabajar con diferentes valores.

    Ejemplo: 
        void encenderLed(int pin){
        digitalWrite(pin, HIGH);
    }

    La función recibe el número del pin mediante el parámetro pin.

    Podemos utilizarla de diferentes maneras: 

        encenderLed(13);

    O 

        encenderLed(0);

    Programa completo: 
        void encenderLed(int pin) {
        digitalWrite(pin, HIGH);
    }

    void setup(){
        pinMode(8, OUTPUT );
        pinMode(13, OUTPUT );
    }

    void loop(){
        encenderLed(8);delay(1000);
    
        encenderLed(13);delay(1000);
    }

    La función es la misma, pero podemos indicarle sobre qué pin debe trabajar.



  5. Función sin parámetros y con retorno.

    En este caso, la función no recibe información, pero devuelve un valor.

    Para devolver un resultado se utiliza return.

    Ejemplo: 
        int obtenerNumero(){
    return 10;
    }

    La función devuelve el número 10.

    Podemos guardar ese resultado en una variable: 

        int numero = obtenerNumero();

    Programa completo: 
         int obtenerNumero() {
        return 10;
    }

    void setup(){
        Serial.begin(9600);
        int numero = obtenerNumero();
        Serial.println(numero);
    }

    void loop(){
    }

    En el monitor seria se mostrará:

    10

    En este caso utilizamos int en lugar de void porque la función devuelve un núumero entero.



  6. Función con parámetros y con retorno.

    Es una de las formas más completas de utilizar una función.

    La función:

    1. Recibe uno o más valores
    2. Realiza una operación.
    3. Devuelve un resultado.

    Ejemplo 
        int sumar(int a,int b) {
    return a + b;
    }

    La función recibe dos números y devuelve su suma.

    Podemos utilizarla de esta manera: 

        int resultado = sumar(5, 3);

    El valor almacenado en resultado será:

    8
    Programa completa. 
        int sumar(int a, int b) {
        return a + b;
    }

    void setup(){
        Serialbegin(9600);
        int resultado = sumar(5, 3);
        Serial.println(numero);
    }

    void loop(){
    }

    Resultado: 8

  7. Resumen de los cuatro tipos

    Tipo de función Parámetros Retorno
    void encender() No No
    void encender(int pin) Sí No
    int obtenerNumero() No Sí
    int sumar(int a, int b) Sí Sí

    Una forma sencilla de recordarlos es:

    Parámetros → Información que entra a la función.

    Retorno → Información que sale de la función.

Ejercicios

  1. Realizar un programa que controle tres LEDs conectados a los pines 8, 9 y 10, utilizando dos funciones sin parámetros llamadas encenderTodos() y apagarTodos(). La primera función debe encender los tres LEDs y la segunda debe apagarlos. El programa debe encender los tres LEDs, esperar 2 segundos, apagarlos, esperar 2 segundos y repetir el proceso.


  2. Conectar un botón al pin 7 y un LED al pin 13. Crear una función llamada leerBoton() que lea el estado del botón y retorne el valor obtenido. En el loop(), utilizar el valor retornado para encender el LED cuando el botón esté presionado y apagarlo cuando no lo esté. Además, mostrar el estado del botón en el Monitor Serial.


  3. Conectar un LCD 16x2 y un LED al pin 13. Crear una función llamada mostrarMensaje() que reciba como parámetros un texto y un número de fila, y muestre el texto recibido en la fila indicada del LCD. En setup() mostrar "Sistema listo" en la primera fila y "Arduino" en la segunda.

    Ayuda:

    Llamado de la función en el setup(): 

       mostrarMensaje("Sistema listo", 0);
mostrarMensaje("Arduino", 1);

  4. Conectar un botón al pin 7, un LED al pin 13 y un LCD 16x2 I2C. Crear una función llamada leerEstado() que reciba como parámetro el número de pin del botón y retorne su estado. En loop(), utilizar el valor retornado para encender o apagar el LED y mostrar en el LCD "Presionado" o "Sin presionar" según corresponda.


  5. Realizar un programa que permita controlar mediante Bluetooth un menú de navegación mostrado en una pantalla LCD 16x2. En la primera fila deberá aparecer Menu: y en la segunda fila se mostrará la opción seleccionada con el formato < Iniciar >. Las opciones disponibles serán Iniciar, Detener, Modelo y Salir. Para desplazarse entre las opciones se deberán recibir mediante Bluetooth los caracteres A para desplazarse hacia la izquierda y D para desplazarse hacia la derecha. Al alcanzar la primera o última opción, el desplazamiento deberá continuar de forma circular, volviendo a la última o primera opción respectivamente.

    Crear una función sin parámetros llamada leerBluetooth() que lea un carácter recibido mediante Bluetooth y retorne dicho carácter. El valor retornado deberá almacenarse en una variable y posteriormente enviarse como parámetro a una función llamada menu(). Esta función deberá recibir además el estado de un pulsador utilizado para ingresar a la opción seleccionada. Según el carácter recibido, deberá actualizar la opción mostrada en el LCD y, si el pulsador de ingreso se encuentra presionado, deberá ejecutar la acción correspondiente. Al seleccionar Iniciar, deberá mostrar durante dos segundos Iniciando...; al seleccionar Detener, deberá mostrar durante dos segundos Deteniendo...; al seleccionar Modelo, deberá mostrar PHC530 y luego regresar automáticamente al menú principal. Finalmente, al seleccionar Salir y presionar el pulsador de ingreso, deberá mostrar Hasta luego! y finalizar el funcionamiento del menú.

    La función leerBluetooth() deberá ser una función sin parámetros y con retorno del tipo char, mientras que la función menu() deberá ser una función con parámetros y sin retorno.
